# 载入 .fcap 壳内实选文件（U12）

- 状态：已确认（U12a；实现未开始）
- 日期：2026-11-03
- 依据：U8 缺口 G4「载入其他 .fcap 包」真实选择器未做端到端；U10/U11 已具备壳侧磁盘另存为，打开侧仍依赖 WebView `<input type="file">`，正式交付不完整

## 背景

正式用法是双击壳 EXE。  
录制落盘（U10）与导出现场包另存（U11）已能走到可见磁盘路径。  
重演页「载入其他 .fcap 包」仍走隐藏文件输入：开发浏览器尚可，壳内未做端到端验收；大文件还常经 UI 读字节再 `session.load`（b64），与引擎已有的 `session.open`（磁盘路径）不对称。

实验室人员需要从 `record\日期\`、U 盘或旁路目录直接打开正式二进制 `.fcap`，并进入重演/报文主路径。

## 目标

1. 壳内点击「载入其他 .fcap 包」（及空态「载入 .fcap」）弹出**原生打开文件**对话框，选定后载入该绝对路径上的会话。
2. 正式路径优先按**磁盘路径**交给引擎（`session.open`），不以「整文件进 WebView 再 b64」为交付主路径。
3. 成功后会话标题/帧列表/重演可用，提示可读；取消选择则**不改**当前会话。
4. 消掉 U8 缺口 G4（壳内手测通过即算关闭）。

## 非目标

- 改 `.fcap` 格式，或改 `session.open` / `session.load` 语义（只接线，不扩协议字段）
- 壳内「导入 .pcap」一并改成原生打开（可后置；本条只收 `.fcap`）
- 多选批量载入、最近文件列表、拖拽进窗（锦上添花，不纳入本轨验收）
- 强制无壳 `npm run dev` 具备原生打开（无壳可保留现有 `<input type="file">` / JSON 演示）
- 载入前强制「未保存确认」弹窗（与现替换会话行为保持一致；不另加）
- E15 MQTT mTLS

## 用户故事

1. 作为调试人员，我希望在壳里点「载入其他 .fcap 包」就能浏览本机 `.fcap`（尤其 `record\日期\`），以便直接重演刚录的包。
2. 作为调试人员，我希望取消打开对话框后当前会话不变，以免误触清空工作现场。
3. 作为调试人员，我希望录制中或重放中尝试载入时得到明确失败提示，而不是半载入坏状态。

## 产品约定（已确认）

| 项 | 约定 |
|----|------|
| 正式入口 | 重演页既有「载入其他 .fcap 包」与空态「载入 .fcap」；壳内改为原生**打开**对话框 |
| 筛选 | 默认筛选 `.fcap`；不必在本条强求同时选 JSON 演示包（无壳预览仍可走旧文件输入） |
| 初始目录 | 优先 `{壳 fieldreplay.exe 所在目录}\record\<YYYY-MM-DD>\`（与 U10/U11 一致；不存在则回退到可打开的父级或系统默认） |
| 取消 | 取消打开 = **不载入**、不清空、不 toast 成功 |
| 成功 | 替换当前内存会话（与现行为一致）；toast/提示含会话标题与帧数；宜带所选路径（可读） |
| 引擎 | 壳内正式路径：拿到绝对路径后走 `session.open`；失败展示引擎错误摘要 |
| 录制中 / 重放中 | 不允许成功载入；沿用引擎拒绝；UI 给可读提示（可先停录/停放） |
| 无壳预览 | 可继续用 `<input type="file">` + 现有 `session.load`/JSON；**正式验收以壳为准** |
| 大文件 | 不以整包进 UI 内存为正式要求；路径打开即可 |

## 验收标准

- [ ] 需求与进度本可指到本文件
- [ ] 壳内点「载入其他 .fcap 包」弹出原生打开对话框；筛选可见 `.fcap`
- [ ] 选定 U10 风格路径下的真实二进制 `.fcap` 后：重演页标题/帧数更新，报文页可见帧，可启动重演主路径
- [ ] 取消打开：当前会话不变
- [ ] 初始目录在存在时可落到当日 `record\日期\`（或可预期的旁路父目录）
- [ ] 录制中或重放中载入：失败提示明确，会话不被部分污染
- [ ] 成功提示含会话信息；壳内宜含实际路径
- [ ] U10/U11 另存为、`--smoke` / 开窗主路径不因本条回归失败
- [ ] U8 缺口 G4 在进度本标记为已消（壳内手测）

## 影响范围

- 壳：原生「打开」对话框 IPC（可与 U10 `pick_save_fcap` 对称，如 `pick_open_fcap`）

- 引擎：无格式/协议必改（已有 `session.open`）；UI 客户端补路径打开封装即可
- 文档：进度本 U8 G4；README 可选补一句「壳内可打开磁盘 .fcap」
