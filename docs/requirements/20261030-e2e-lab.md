# 端对端实验室联调（E2E Lab）

- 状态：进行中（分步手测）
- 日期：2026-10-30
- 依据：产品主线已收口；用本机假设备 + FieldReplay + 假上位机做整链路验收

## 目标

在本机串起：**假设备发数 → FieldReplay 录制 → 停设备 → FieldReplay 重演 → 假上位机收显**。  
验证多通道时序与载荷能否保真送达，不替代引擎 `self-check`。

## 通道约定（模拟期）

| 通道 | 假设备 | FieldReplay 录 | 重演灌向 | 假上位机 |
|------|--------|----------------|----------|----------|
| 视频 | MediaMTX + ffmpeg → RTSP | 拉 `rtsp://127.0.0.1:8554/...` | 单路 RTSP listen 或 UDP | 播放器 / 可选拉流 |
| UDP 状态 | 周期文本 UDP | bind 收包 | 发到假上位机端口 | 文本/HEX 显示 |
| TCP 激光状态 | 周期文本 TCP | server/client 收 | 角色取反灌回 | 按行解析显示 |
| MQTT | 本机 Broker + 发布 | 订阅 | 向 Broker 发布 | 订阅显示 |

模拟帧建议用可读文本（如 `STAT,...` / `LASER,...`），便于肉眼验收；不绑真实激光二进制协议。
