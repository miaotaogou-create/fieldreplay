# 真实串口增强（E8）

- 状态：E8a 已收口；E8b/E8c 待做
- 日期：2026-10-30
- 依据：MVP 串口已勾选但自检为内存环回；增强项排序见进度本

## 背景

引擎已支持 Windows Win32 实口录放，自检与 `io_accept` 仍走内存环回。UI 串口列表为写死选项，现场易选到不存在的口。实口路径是工业上位机主路径之一，应优先补齐「看得见口、开得住口、有手测清单」。

## 目标模型

| 阶段 | ID | 内容 | 非目标 |
|------|-----|------|--------|
| E8a | 本会话落地 | 本机 COM 枚举；控制面 `serial.list`；UI 录/放侧用引擎列表（可刷新） | 不装驱动；不强制依赖 com0com |
| E8b | 待做 | 实口/虚口手测清单；可选环境变量门控的实口自检 | 不把无 COM 的 CI 判失败 |
| E8c | 待做 | 打开失败可读错误；波特率/校验与列表反馈小抛光 | 不重写 Win32 层；不引入 serialport crate |

## 用户故事

1. 作为现场调试人员，我希望从本机真实串口列表里选口，以便少填错 COM。
2. 作为研发人员，我希望有一份虚口（如 com0com）手测步骤，以便在无设备时仍能验通录放。

## E8a 验收

- [x] `serial::list_ports()`：Windows 枚举本机 COM；无口时返回空列表（不报错）
- [x] 控制面 `serial.list` → `{ "ports": ["COM3", ...] }`（已排序）
- [x] UI 重演页：引擎已连时刷新可用口；未连时保留本地兜底列表
- [x] UI 录制「添加串口」：引擎已连时可从本机口提示/选择
- [x] 仍仅标准库；`cargo test` / `self-check` 不因无实口失败

## E8b / E8c 验收（后续）

- [ ] 文档手测：虚口对一端灌数、一端录；重放写对端口
- [ ] 可选：`FIELDREPLAY_SERIAL_PAIR=COMa,COMb` 时跑通实口环回自检
- [ ] 打开失败时控制面/UI 可见系统错误摘要

## 非目标

- 替代专业串口调试助手（波形、电平）
- Linux/macOS 实口（当前引擎串口仅 Windows）
- MQTT TLS / pcap（见 E9 / E10）

软件工程师 / 测试：E8b 虚口手测清单 + 可选环境变量实口自检；其后 E8c。
