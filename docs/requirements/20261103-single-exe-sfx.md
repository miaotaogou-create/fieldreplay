# 单 EXE 自解压交付（G2）

- 状态：已确认（待实现）
- 日期：2026-11-03
- 依据：现场选定；绿色目录拷贝多文件易漏件；希望 U 盘/网盘只发 **一个 EXE**；U10 落盘相对壳目录，解压必须落到可预期、可写位置

## 背景

当前正式交付是绿色目录 `pack/FieldReplay/`（壳 + 引擎 + `ui/dist` 等）。  
「单入口」体验已满足（双击壳出窗口），但分发仍是整夹拷贝，现场易漏 DLL/引擎或路径被拆散。

## 目标

1. 额外提供一种交付物：**单个 `.exe`**，双击即可用（无需用户先手动解压整夹）。
2. 首次（或版本变更后）自动展开为与现绿色包等价的布局，再启动现有壳。
3. 绿色目录打包 **继续保留**（不替换、不废弃）。

## 非目标

- 安装向导、开始菜单、卸载程序、注册表安装、自动更新
- 改录放功能、控制面协议、`.fcap`、U10 路径语义（仍相对**壳 EXE 所在目录**）
- 强制取消绿色目录交付
- 单文件「永不落盘旁路文件」（运行时仍需解出引擎/UI；物理唯一只针对**分发物**）
- macOS / Linux；商店上架；代码签名（可后置；本条不阻塞）
- 「导出改保存位置」（已排期为 **U11**，本条不做）

## 用户故事

1. 作为现场人员，我希望只拷一个 EXE 到工控机/U 盘，双击就能开 FieldReplay，以免漏拷旁路文件。
2. 作为发放同事，我希望与绿色包二选一或并存发放，不强迫现场改习惯。

## 产品约定（已确认）

| 项 | 约定 |
|----|------|
| 分发物 | 一个自解压启动器 EXE（内嵌与当前绿色包等价的内容） |
| 绿色包 | `tools/pack_green` 产物仍可用；自解压包在绿色包之后生成 |
| 解压目录（优先） | 启动器 **同级** 下的 `FieldReplay\`（便于 U 盘旁路可见、录制包好找） |
| 解压目录（回退） | 若同级不可写：`%LOCALAPPDATA%\FieldReplay\` |
| 复用 | 目标目录已存在且 **版本标记与内嵌包一致** → 跳过解压，直接启动壳 |
| 版本变更 | 内嵌包版本与目录标记不一致 → 覆盖更新后再启动（不得静默跑旧旁路） |
| 启动 | 解压（或复用）完成后启动其中的 `fieldreplay.exe`（现有壳）；本条不改壳内录放逻辑 |
| 录制路径 | 仍按 U10：相对**壳**目录的 `record\日期\`；因此壳必须从解压目录启动 |
| 图标 | 启动器 EXE 尽量带与 G1 相同产品图标（资源管理器可辨） |
| 失败反馈 | 解压/无写权限/拉起失败须有可见提示（MessageBox 或等价），不得无声退出 |
| 杀软 | 自解压属高误报形态；文档注明「可能被拦截」；本条不要求过特定杀软白名单 |

## 验收标准

- [x] 需求与进度本可指到本文件；G2 拆分可勾选
- [x] 存在可重复的打包步骤，产出 **单个** 自解压 EXE（路径写入 README 或 `tools/` 说明）
- [ ] 在空目录双击该 EXE：自动展开旁路并出现 FieldReplay 本机窗口（需本机已有 WebView2，与绿色包相同前提）
- [ ] 第二次双击（同版本）：不重复整包解压（或可观测为秒开/跳过），仍能正常开窗
- [ ] 解压目录内布局与绿色包等价（至少含壳、引擎、`ui\dist`），双击其中壳亦可单独运行
- [ ] 同级不可写时回退到 `%LOCALAPPDATA%\FieldReplay\` 仍能开窗；失败有提示
- [ ] `pack_green` 与壳 `--smoke` / 开窗主路径不因本条回归失败
- [x] 绿色目录交付说明仍保留；自解压为并行选项

## 影响范围

- 打包：`tools/` 新增或扩展脚本（先绿包，再打自解压）
- 可能新增：极薄启动器工程或脚本生成的 SFX 外壳（不含录放热路径）
- 文档：`README.md` / 进度本交付说明
- UI / 引擎 / 控制面：**无功能变更要求**（除非启动器需写入版本标记文件）
