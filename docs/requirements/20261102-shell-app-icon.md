# 壳应用图标（G1 · 交付抛光）

- 状态：已收口（G1b）
- 日期：2026-11-02
- 依据：绿色包 / 开发壳运行时，任务栏与资源管理器仍显示 Windows 默认应用图标；产品主线功能已收口，交付观感缺口优先

## 背景

FieldReplay 正式用法是双击 `fieldreplay.exe` 出本机窗口。  
当前壳只设置了窗口标题，仓库内无任何应用图标资源，任务栏与 EXE 文件均落回系统默认图标，现场不易辨认、也不像成品工具。

## 目标

1. 运行中的主窗口在 **任务栏**、**Alt+Tab** 上显示 **本产品图标**，不再是系统默认白窗图标。
2. 绿色目录内的 **`fieldreplay.exe` 文件图标** 同步为本产品图标（资源管理器一眼可辨）。
3. 图标资源进仓、可替换；接线一次，以后只换图不改产品行为。

## 非目标

- 安装程序、开始菜单快捷方式、卸载项、商店上架素材
- 改产品功能、控制面协议、`.fcap`、E2E 夹具行为
- 多套皮肤 / 深浅色自适应多套图标（一枚通用标即可）
- 浏览器 `favicon`（正式交付不走系统浏览器；开发预览不强制本条）
- 引擎子进程 `fieldreplay-engine.exe` 的文件图标（本条只要求壳入口 EXE）

## 用户故事

1. 作为现场人员，我希望任务栏上能立刻认出 FieldReplay，以便多窗口时不点错。
2. 作为领取绿色包的同事，我希望文件夹里的主 EXE 自带产品图标，以便无需读文件名也能找到入口。

## 产品约定（已确认）

| 项 | 约定 |
|----|------|
| 作用范围 | `shell/` 主窗口 + 打包后的壳入口 `fieldreplay.exe` |
| 必须覆盖 | 任务栏按钮、Alt+Tab 缩略旁图标、资源管理器中壳 EXE 图标 |
| 视觉 | 无现成品牌稿时，允许落地 **一枚极简产品标**（可辨识、非系统默认）；后续只替换资源文件即可升级美术 |
| 格式 | Windows 常用多尺寸 `.ico`（至少含 16 / 32 / 256 之一组清晰档）；源矢量或 PNG 可并存便于改稿 |
| 打包 | `tools/pack_green.*` 产出目录中的壳 EXE **自带**嵌入图标，不依赖旁路再拷一份才能显示文件图标 |
| `--smoke` | 可不打开窗口；本条不以 smoke 替代任务栏手测 |
| 失败降级 | 图标资源缺失时允许回退系统默认，但 **正常打包路径不得缺失** |

## 验收标准

- [x] 仓库内有明确的应用图标资源路径（如 `shell/assets/` 或约定目录），文档/进度本可指到
- [x] 本地启动壳（非 smoke）后：任务栏按钮为产品图标，**不是** Windows 默认应用图标
- [x] Alt+Tab 中该窗口旁为同一产品图标（或系统等价展示）
- [x] `tools\pack_green.bat` 成功后，`pack\FieldReplay\fieldreplay.exe` 在资源管理器中显示产品图标
- [x] 替换图标资源并重新打包后，无需改业务逻辑即可换标（接线稳定）
- [x] 既有 `--smoke`、开窗主路径不因本条回归失败

> 落地：`shell/assets/fieldreplay.ico` + `build.rs`（winres 嵌入）+ `window.rs` `Icon::from_resource(1, …)`；`pack_green` smoke 通过；EXE 抽取图标中心色为产品标 slate。

## 影响范围
