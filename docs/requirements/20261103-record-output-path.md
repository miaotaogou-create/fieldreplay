# 录制落盘路径可见与可选（U10）

- 状态：已实现（U10a–U10c 收口）
- 日期：2026-11-03
- 依据：现场开录后不知数据写到何处，也无法指定路径；引擎已有 `record.start.out`，UI 未接；默认落 `%TEMP%` 不友好

## 背景

正式用法是双击壳 EXE 开窗录制。  
当前开录不传 `out`，引擎写入临时目录；停止提示只带文件名。现场找不到包、也不敢依赖「导出再另存」。

## 目标

1. 开录前界面展示**将要写入**的完整路径（默认可预期）。
2. 可浏览或手改路径；开录按该路径落 `.fcap`。
3. 录制中路径只读；停止后仍能看见实际写入路径。

## 非目标

- 改「导出现场包」的浏览器下载另存流程（另立）
- 单 EXE 自解压交付（后置备选）
- 改 `.fcap` 格式或控制面除「使用已有 `out`」以外的语义
- 浏览器开发预览强制具备原生另存为（无壳时可手填绝对路径）

## 用户故事

1. 作为现场人员，我希望开录前就看到文件会写到 EXE 旁边的 `record` 日期目录，以便收工直接拷文件夹。
2. 作为现场人员，我希望能改保存位置（例如换盘），以免默认目录空间不足。

## 产品约定（已确认）

| 项 | 约定 |
|----|------|
| 默认路径 | `{壳 fieldreplay.exe 所在目录}\record\<YYYY-MM-DD>\<建议文件名>.fcap`（本地日历日） |
| 建目录 | 默认路径的 `record` 与当日日期目录不存在则创建 |
| 不再默认 | `%TEMP%\fieldreplay_live\…`、用户「文档」库 |
| 选择 | 壳原生「另存为」（筛选 `.fcap`）；初始目录优先当日 `record\日期`；可手改文本 |
| 开录 | UI 必须把选定绝对路径作为 `record.start.out` 下发 |
| 录中 | 路径只读；以引擎返回的 `out` 为准展示 |
| 恢复默认 | 可回到 `EXE\record\当天\` 建议名；不强制跨天记住用户自选目录 |
| 无壳预览 | 「浏览」可禁用；允许手填绝对路径；提示正式用法在壳内 |

## 验收标准

- [x] 需求与进度本可指到本文件与默认路径约定
- [x] 壳内启动后，录制页在开录前显示形如 `…\record\YYYY-MM-DD\….fcap` 的默认绝对路径
- [x] 不改路径直接开录：`.fcap` 出现在该默认路径；停止后提示/展示含该路径
- [x] 「浏览」可选其它路径；开录写入所选路径
- [x] 录制中不可改路径
- [x] `--smoke` 与开窗主路径不因本条回归失败（U10b 已验；U10c 仅 UI 接线）
- [x] 控制面仍兼容未传 `out` 的旧客户端（引擎可保留原 TEMP 回退，正式 UI 必传 `out`）

## 影响范围

- 壳：默认路径计算、另存为对话框、IPC 回传
- UI：录制页路径行；`startRecord({ out })`
- 引擎：无协议变更（已有 `out`）；正式路径不依赖改默认 TEMP
- 打包 / E2E：无强制变更（绿色包旁会出现 `record\` 目录属预期）
