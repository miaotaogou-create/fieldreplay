# 录制页通道卡片：右键编辑 / 删除（U9）

- 状态：已确认（待实现）
- 日期：2026-11-02
- 依据：现场手测时通道卡片仅能勾选启用，无法改参或删掉配错的通道；右键目前冒出浏览器默认菜单，无产品动作

## 背景

录制页「现场输入信道」卡片网格紧凑：勾选开关、名称、类型摘要、帧数。  
用户配错端口 / 想改名 / 想去掉不用的通道时，只能再「添加」堆新卡，或整页刷新丢配置——现场不便。  
右键是桌面工具常见入口，且不挤占卡片布局；同时需拦住 WebView2/浏览器默认菜单，避免「返回」等无关项抢占右键。

## 目标

1. 在通道卡片上提供 **编辑**、**删除**，路径短、反馈明确。
2. 主入口为 **右键菜单**；不把铅笔/垃圾桶常驻铺满卡片。
3. 录制进行中（含暂停）不允许改参或删通道，避免半截会话配置漂移。

## 非目标

- 录制中动态增删引擎通道 / 热切换 listen 口（仍须停录后改配置再开录）
- 重演页多路目标区的同类菜单（本条仅录制页通道列表）
- 批量删除、拖拽排序、通道复制
- 改通道 **类型**（UDP→TCP 等视为删旧加新；本条编辑不开放改类型）

## 用户故事

1. 作为现场调试人员，我希望右键通道卡片即可编辑名称与参数，以便配错端口后立刻改正，不必另加一张卡。
2. 作为现场调试人员，我希望右键即可删除不用的通道，以便列表保持干净。
3. 作为桌面用户，我希望右键不再弹出浏览器「返回」等默认菜单，以便右键专用于通道操作。

## 产品约定（已确认）

| 项 | 约定 |
|----|------|
| 作用范围 | 录制页 `FieldRecorderView` 通道卡片（`ChannelConfig` 列表） |
| 主入口 | 卡片上 **右键** → 菜单：**编辑**、**删除** |
| 系统菜单 | 在卡片上右键须 **阻止** 浏览器/WebView 默认上下文菜单 |
| 左键 | 保持现行为：点卡片 / 勾选框 → 仅切换 `enabled`（与菜单分离） |
| 编辑 | 打开与「添加通道」同构的表单，**预填**当前名称与参数；**类型只读不可改**；保存后更新该卡，id 不变 |
| 删除 | 二次确认（文案需带通道名称）；确认后从列表移除；允许删到 0 条（回到已有空态） |
| 录制中 / 已暂停 | 菜单仍可打开，但 **编辑、删除不可用**（禁用 + 简短原因，如「请先停止录制」）；或直接不提供可点项——须有明确不可用反馈 |
| idle | 可编辑、可删除 |
| 可发现性（锦上添花） | 悬停出现 `⋯` 打开同一菜单；或双击进入编辑。本条验收 **不强制**；有则更好 |

## 验收标准

- [ ] 在任意通道卡片上右键：出现含「编辑」「删除」的产品菜单；**不出现**浏览器默认菜单（如返回）
- [ ] 选「编辑」：表单预填正确；改名称或端口等参数后保存，卡片摘要与后续开录使用的配置一致；通道 id 不变
- [ ] 编辑时无法改通道类型
- [ ] 选「删除」→ 确认后卡片消失；取消则仍在
- [ ] `recordState` 为 recording 或 paused 时：无法完成编辑保存或删除（有禁用或等价拦截 + 可见说明）
- [ ] idle 且列表可删至空；空态与「添加通道」入口仍可用
- [ ] 左键勾选启用/禁用行为与改前一致，不被菜单逻辑破坏

## 影响范围

- UI：`FieldRecorderView` 通道卡片；添加通道弹窗复用或抽「编辑」模式
- 状态：`App`（或等价）需具备更新单通道、按 id 删除通道的能力（目前仅有添加与勾选）
- 引擎 / `.fcap` / 控制面：无（仅改开录前的 UI 配置列表）
